健康AI记隐私政策

生效日期：2026年11月1日　·　最近更新：2026年11月1日

概要：健康AI记主要在您的设备本地保存健康指标、化验结果、检查报告和家庭成员档案。我们不运营用于接收报告内容的自建服务器，也不出售您的个人信息。只有当您主动启用并同意云端识别时，您选择的报告页面才会通过 HTTPS 直接发送给 DeepSeek API 处理。

健康AI记开发团队（以下简称“我们”）重视您的隐私。本政策说明健康AI记（以下简称“本 App”）如何处理信息、使用设备权限，以及您可以如何管理和删除数据。使用本 App 前，请阅读并理解本政策。

1. 本 App 的定位

本 App 用于个人和家庭健康数据记录、报告整理、趋势展示和复诊沟通辅助，不提供诊断、医学影像解读、检验或检查结果解释、治疗、用药、停药或急救建议。本 App 只转录化验结果和医生已经出具的文字检查报告，不分析 X 光片、CT/MRI 切片、B 超图像、内镜图像、病理切片或其他原始医学影像。

2. 本 App 处理的信息

信息类别示例主要用途
人员档案档案名称、与使用者的关系区分本人及家庭成员的独立健康档案
健康与医疗资料身体指标、化验结果、参考范围、异常标记、检查所见、检查结论、报告日期、医院名称、备注记录、归档、展示趋势和生成就诊摘要
报告附件用户拍摄或选择的图片、导入的 PDF 及其页面图片报告识别、原报告核对和本地归档
应用设置字体大小、显示模式、关注指标、云端识别授权状态保存您的使用偏好
DeepSeek 配置用户自行填写的 API Key由用户自己的 DeepSeek 账户发起报告识别请求
购买状态家庭档案功能的购买结果恢复或确认已购买权益；支付由 Apple 等应用商店处理

3. 本地存储

  • 结构化健康数据、人员档案、应用设置和报告附件主要保存在本 App 的设备沙盒中。
  • DeepSeek API Key 保存在操作系统提供的安全存储中，不写入健康数据备份。
  • 本 App 不要求注册健康AI记账户，也不提供自建云同步服务。
  • 卸载 App 通常会删除 App 沙盒内的数据；但您主动导出到“文件”、iCloud Drive、第三方云盘或其他位置的副本不受卸载影响。

4. DeepSeek 云端识别

云端识别是可选功能。首次使用前，本 App 会明确说明数据将发送给 DeepSeek，并征求您的同意。您可以在设置中关闭云端识别。

发送内容

  • 您主动选择用于识别的报告照片；
  • PDF 在本机转换生成的页面图片；
  • 用于限定“只转录文字、不进行诊断或医学影像分析”的处理指令；
  • 请求过程中由网络服务通常产生的网络与技术信息，例如 IP 地址、设备或请求日志，具体以 DeepSeek 的规则为准。

处理方式

  • 请求通过 HTTPS 直接提交给 DeepSeek API；健康AI记没有自建图片中转服务器。
  • API Key 由用户自行提供，相关费用、账户记录和配额由该 DeepSeek 账户承担。
  • DeepSeek 对输入内容、输出内容、日志和网络信息的处理、保存期限、跨境存储及用户权利，受 DeepSeek 的政策、开放平台条款和账户设置约束。
敏感信息提示：医疗报告可能包含姓名、年龄、医院、检查结果等敏感个人信息。请仅处理您本人或已获得合法授权的资料，并在发送前确认报告中包含的信息。

5. 设备权限

  • 相机：用于拍摄纸质报告或家用仪器屏幕。只有您主动拍摄时才会使用。
  • 照片与文件：用于选择报告图片、导入 PDF、导入或导出备份，以及保存就诊摘要。
  • 网络：用于在您同意后访问 DeepSeek API，以及完成应用商店购买验证等系统服务。

您可以在设备系统设置中管理权限。拒绝相机或照片权限不会影响手动录入，但相应的拍摄或选择功能将不可用。

6. 数据备份与导出

  • 您可以导出 .myhealthbackup 备份文件。备份包含人员档案和结构化健康数据，不包含 DeepSeek API Key、原报告附件或购买凭证。
  • 您可以生成就诊摘要 PDF，并通过系统分享功能保存或发送。
  • 备份文件、PDF 或其他导出内容一旦离开本 App，将由您选择的文件位置、云盘、通信工具或接收者处理。请自行选择可信目的地并妥善保管。

7. 信息共享与披露

我们不出售或出租您的健康数据。除以下情形外，本 App 不会主动向第三方提供您的数据：

  • 您明确选择并同意使用 DeepSeek 云端识别；
  • 您主动导出、分享或备份数据；
  • Apple 或其他应用商店为处理购买、退款和恢复购买而处理交易信息；
  • 法律法规要求，或为保护用户及他人生命、财产与合法权益所必需的情形。

8. 数据保留、删除与您的选择

  • 本地数据通常保留至您删除对应记录、使用“清空所有数据”或卸载 App。
  • 您可以删除单份化验报告、检查报告或具体指标记录。
  • 您可以在设置中清空全部人员档案、健康记录、报告附件和已保存的 DeepSeek 配置。
  • 您导出到本 App 之外的文件需要由您在对应位置另行删除。
  • 已经发送给 DeepSeek 的内容及相关请求日志，应依据 DeepSeek 提供的账户设置和隐私权利渠道进行管理。

9. 家庭成员与未成年人资料

本 App 支持为家庭成员建立相互独立的档案。录入、拍摄或上传他人资料前，您应确认自己有权处理该资料，并在适用情况下取得本人、监护人或其他合法授权人的同意。监护人应负责未成年人资料的录入和管理。

10. 数据安全与准确性

我们采用设备沙盒、系统安全存储和 HTTPS 等措施降低未经授权访问的风险。但任何存储或网络传输方式都无法保证绝对安全。OCR 和生成式 AI 可能识别错误、遗漏或混淆内容，请在保存前逐项对照原始报告核对，且不要依据本 App 的识别结果自行作出医疗决定。

11. 隐私政策网页的托管

本政策网页通过 GitHub Pages 提供。访问网页时，GitHub 可能为安全、运行和日志目的处理 IP 地址等网络信息。相关处理适用 GitHub General Privacy Statement。本页面自身不使用广告、分析脚本或第三方字体。

12. 政策更新

我们可能因功能、第三方服务或法律要求变化而更新本政策。更新后的政策会在本页面发布并注明最新日期。若更新对您的权利产生重大影响，我们会通过适当方式提示。
